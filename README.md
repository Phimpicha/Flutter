# Yu Express Flutter App

แอปตัวอย่างสำหรับ Yu Express ที่เน้นการติดตามพัสดุ สร้างรายการจัดส่ง และเข้าถึงบริการช่วยเหลือได้สะดวก

## โครงสร้างหน้าหลัก
- Hero section สำหรับโปรโมชันและการสร้างรายการจัดส่ง
- Quick actions เพื่อสแกนพัสดุและค้นหาสาขา
- Tracking card สำหรับตรวจสอบสถานะพัสดุ
- Support card เพื่อเข้าถึงบริการช่วยเหลืออย่างรวดเร็ว

## การเริ่มต้น
1. ติดตั้ง Flutter SDK
2. รันคำสั่ง
   ```bash
   flutter pub get
   flutter run
   ```
